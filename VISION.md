# Projektvision

Dieses Projekt soll mir dabei helfen, mit Hilfe von Claude Code Cloud jedes beliebige Thema
zu lernen. Typische Anwendungsfälle sind das Lernen von Sprachen (Spanisch, Griechisch, etc.),
Programmiersprachen, Mathematik (z.B. Galois-Theorie, Kategorientheorie, etc.), Physik (z.B.
Quantenfeldtheorie, Stringtheorie etc.) und vieles mehr.

Als User möchte ich Claude Code Cloud ein Thema nennen, das ich lernen möchte. Es soll dann 
eine Art Lehrbuch (auf github pages) erstellen, das mir das Thema strukturiert, didaktisch 
geschickt und unterhaltsam beibringt. Claude soll mir erstmal ein Outline für das Buch
vorschlagen und ein Beispielkapitel schreiben, anhand dessen wir dann diskutieren, ob mir
der Stil oder Ansatz gefällt oder nicht. Basierend auf meiner Antwort soll Claude das anpassen,
solange bis wir uns geeinigt haben. Dann soll Claude das Buch schreiben und auf github pages
publishen. Der Clou: während des Lesens möchte ich parallel weiter mit Claude reden und
bitten, Änderungen vorzunehmen und Fragen zu beantworten und einzuarbeiten.

Hierfür sollte es eine Reihe von Custom Claude Skills / Agents / Commands geben. Lass uns
darüber diskutieren, welche und wie die zusammenarbeiten.

Wichtig ist, dass das Projekt mit jeder Art Thema zurecht kommt und sich ggf. selbst die
nötigen Skills recherchiert und sich beibringt. Das Projekt sollte Bücher in einer vom User
festzulegenden Sprache erstellen können, nicht nur deutsch oder englisch.

Lass uns darüber reden, was hier noch alles geklärt werden muss. Vielleicht hast Du ja auch
Ideen und Vorschläge, an die ich noch gar nicht gedacht habe.
